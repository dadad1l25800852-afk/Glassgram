# YouFree 0.3 — Original YouTube Beta Companion

## Что это

Вместо собственного YouTube-клиента YouFree теперь запускает **установленный оригинальный
YouTube от Google**, без изменения его APK, его подписи или его интерфейса. Поддерживается
тёмная панель настроек и разрешаемая пользователем плавающая кнопка поверх YouTube.

На дату создания проекта, 23 ноября 2026 года, среди опубликованных сборок найдена
бета YouTube **21.47.483**, но YouFree **не скачивает и не распространяет** APK YouTube.
Официальную бету пользователь устанавливает сам через Play Store / beta program.
После обновления YouTube через Google Play кнопка и подключение должны оставаться
отдельными от версий приложения (требует тестирования устройства).

## Подключение

### 1. VPN-ссылка
- Вставь открытую ссылку VLESS, Trojan, SS, VMess либо HTTPS-подписку.
- YouFree использует libXray v26.11.9 для проверки задержки к YouTube и выбирает
  доступный сервер; затем **экспериментальный** VpnService запускает Xray
  с TUN-интерфейсом. С помощью Android per-app VPN направляется только трафик
  пакета com.google.android.youtube, без root.
- Подписка сохраняется в настройках с Android Keystore AES-GCM, не коммитится в Git.
- **Android спросит стандартное согласие на VPN.** Доступность видео на устройстве
  и в сетях операторов России пока не проверена.
- Нужен работающий личный сервер/подписка. Нет бесплатных вымышленных адресов.
- Реализация TUN привязана к физическому интерфейсу, обнаруженному до поднятия VPN,
  чтобы избежать циклической маршрутизации. Переключение Wi-Fi/мобильной сети,
  IPv6, QUIC, DNS и параметры разных серверов требуют полевых испытаний.
- Во время запуска сервис выводит уведомление; если Xray вернёт ошибку,
  сервис выключит VPN. Статус "активно" означает запуск ядра, а не проверенную
  работу произвольного видео.

### 2. ByeByeDPI
- В текущей сборке кнопка **открывает установленный ByeByeDPI** от romanvht
  (или оригинальный ByeDPIAndroid). Если приложение отсутствует, она
  открывает официальный исходный репозиторий для установки.
- Встраивания нативного движка ByeByeDPI в APK **пока нет**; он выполняется
  другим приложением. Поддержка произвольной ссылки стратегии ByeByeDPI
  внутри YouFree **не реализована**.
- ByeByeDPI использует локальный Android VPN-интерфейс без внешнего VPN-сервера;
  Android допускает только один активный VPN на профиль.
- Официальный исходный код: https://github.com/romanvht/ByeByeDPI
- Установи и настрой ByeByeDPI отдельно; после запуска открывай Google YouTube.

### 3. Плавающая кнопка
- В YouFree нажми "Включить плавающую кнопку".
- Разреши "Поверх других приложений" в системных настройках Android и повтори.
- Открой YouTube кнопкой "▶ Открыть YouTube" — появится небольшая тёмная
  панель с красным ▶. Перетаскивай её и нажимай для открытия настроек.
- Это Android overlay, а не инъекция кода в проприетарный YouTube.
- Уведомления позволяют системе держать управляющий сервис в foreground.
- Можно скрыть кнопку из YouFree.

## Собрать APK

Репозиторий содержит Kotlin + Compose проект, Go backend legacy (не нужен
для оригинального YouTube) и .github/workflows/android-apk.yml.
После push в main GitHub Actions собирает debug APK (если сборка прошла):
Actions -> Build YouFree APK -> последний запуск -> Artifacts -> YouFree-Android-APK.

## Ограничения и честный статус

- Не является форком/патчем закрытого приложения YouTube.
- Отображается поверх официального YouTube, не изменяя layout внутри него.
- Выбор самого быстрого сервера основан на задержке/доступности
  generate_204, не на воспроизведении видео: 4K и стабильность не гарантируются.
- ByeByeDPI в этой сборке **внешнее приложение**.
- VpnService на оригинальном YouTube **нельзя заменить** WebView-прокси из
  предыдущей версии, поэтому здесь отдельный TUN-движок.
- **Воспроизведение реальных роликов в России, VPN/TUN и поведение overlay
  пока не проверено на телефоне**; успешная сборка GitHub — не гарантия работы.
- Старый экспериментальный клиент остался в коде, но не открывается при запуске.

Применимые технологии: Android VpnService API,
https://developer.android.com/develop/connectivity/vpn ;
Xray TUN support,
https://github.com/XTLS/Xray-core/blob/main/proxy/tun/README.md ;
libXray https://github.com/XTLS/libXray .
