# YouFree — самостоятельный Android-клиент с VPN и ByeDPI

Это **один APK**, сделанный с нуля на Kotlin/Jetpack Compose:
- нативные вкладки Главная, Поиск, Shorts, Сеть и Библиотека;
- нативные карточки видео; официальный YouTube iframe для воспроизведения;
- VPN-совместимые открытые ссылки VLESS/Trojan/SS/VMess через встроенный XTLS/libXray;
- встроенный **настоящий** ByeDPI C engine (от romanvht/ByeByeDPI, GPL-3.0), без отдельного приложения;
- маршрутизация внутри YouFree через WebView proxy override (без Android VpnService и без root);
- автоматическая проверка доступных VPN-узлов и выбор минимальной задержки.

## Честные ограничения
- Это не APK компании Google и не исходный/модифицированный официальный клиент YouTube.
  Закрытый код YouTube, Google-сервисы и подпись Google **не входят** в приложение.
- Для поиска и главной нативной ленты требуется **свой YouTube Data API v3 key**.
  Ключ вводится пользователем в настройках и остаётся на устройстве. Без ключа
  приложение не подделывает результаты и объясняет, как включить поиск.
- Воспроизведение использует официальный iframe (WebView внутри нативного плеера).
  Некоторым видео нужна авторизация или разрешение на embedding; YouTube
  может возвращать ошибку 153/DRM. Full YouTube Premium/account features нет.
- Для просмотра без блокировок нужен реально работающий VPN-сервер или
  подходящая ByeDPI стратегия. Нельзя гарантировать работу у каждого
  провайдера. Проверено только компилирование, не воспроизведение в РФ.
- В режиме «VPN-подписка» трафик **только YouFree** идёт через Xray.
  Это встроенный application-level proxy, а не системный VPN.
- ByeDPI использует native SOCKS5 proxy + локальный HTTP CONNECT мост,
  направляя WebView запросы через движок, без VpnService.
- QUIC/HTTP3 перехватывать через этот WebView proxy вариант нельзя.
- Поддерживаются только открытые подписки; зашифрованные happ://crypt
  не расшифровываются. Не отправляй свои секретные ссылки в GitHub.

## Исходники ByeDPI и лицензия

Проект распространяется на условиях GPL-3.0-only. При GitHub Actions сборке
оригинальный ByeByeDPI от romanvht версии commit
`ee87264e3bab779d3c23e41e11c45d5f8189faec` извлекается со всеми
submodules и компилируется в `libbyedpi.so`. Соответствующие исходники
доступны по https://github.com/romanvht/ByeByeDPI/tree/ee87264e3bab779d3c23e41e11c45d5f8189faec
и в его GPL-3.0 зависимостях.

libXray v26.11.9: https://github.com/XTLS/libXray/releases/tag/v26.11.9

## Собрать / скачать с телефона

1. Открой GitHub → Actions → **Build native YouFree APK** → последний запуск.
2. При успешном результате скачай **YouFree-APK** из Artifacts.
3. В стандартных «Файлах» Android сначала **извлеки** YouFree.apk из ZIP,
   затем установи APK, не открывая его прямо из RAR.
4. В YouFree зайди во вкладку «Сеть» и введи HTTPS/VLESS-подписку либо
   строку аргументов ByeDPI, например `--tlsrec 3+s`. Подключение выбирается вручную.
5. В разделе «Библиотека» можно ввести YouTube Data API key для нативного поиска.

Для Android Studio вручную положи `libXray.aar` в `app/libs`,
затем скопируй `app/src/main/cpp` из pinned ByeByeDPI checkout
с обновлёнными submodules и открой проект в Android Studio.

## Безопасность
- Proxy listen address — только 127.0.0.1. Локальный прокси может
  быть доступен другим приложениям устройства; для публичного релиза
  требуется изоляция и аудит.
- Подписки и API key сохраняются локально, но любой установленный
  APK требует доверия к производителю. Транспорт защищён TLS.
- ByeDPI нельзя запускать повторно в одном native-процессе после остановки:
  сервис вынесен в отдельный Android process и перезапускается отдельно.
