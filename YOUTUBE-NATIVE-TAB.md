# YouFree · вкладка прямо внутри YouTube

## Архитектура (вместо приложения-перенаправителя)

Используется **модифицированный экземпляр оригинального YouTube**, а не
WebView, launcher или Android-системная плавающая кнопка.

```
Оригинальный YouTube APK, предоставленный владельцем устройства
                  +
Собранный из этого репозитория модуль YouFree Tab
                  +
LSPatch в Integrated/Embedded mode (нужна совместимая версия Android)
                  ↓
Пропатченный YouTube.apk с собственной подписью
                  ↓
Нативная лента YouTube + попытка добавить вкладку «Сеть»
```

Пропатченный YouTube является неофициальной модификацией Google YouTube.
Он **не может быть подписан ключом Google** или обновляться из Play Store как
официальный APK. Существующая системная копия YouTube может мешать установке;
возможности Google-входа и воспроизведения необходимо тестировать отдельно.

## Что есть в модуле

- Код Xposed-модуля, который при запуске именно пакета
  `com.google.android.youtube` ищет горизонтальную нативную навигацию
  у нижней границы экрана, проверяет наличие известных названий вкладок
  и добавляет туда элемент «Сеть».
- Тёмная панель открывается **в том же Activity YouTube**, без перенаправления
  в отдельное приложение. Два режима: VPN и ByeByeDPI.
- Поле ввода сохраняет текст в локальных SharedPreferences этого YouTube.
- Модуль не читает, не перехватывает и не отправляет пароли или токены Google.

## Пока не работает — честный статус

- **Реальная вкладка на актуальной бете ещё не проверена.** В 21.x
  навигация может быть не LinearLayout или иметь другие подписи. Тогда
  модуль намеренно ничего не рисует вместо поддельной вкладки.
- **Сетевой движок, активация VPN и ByeByeDPI в этом модуле отсутствуют.**
  Сохранение ссылки не запускает подключение. Не называем это готовым VPN.
- Нельзя собрать полноценный пропатченный YouTube.apk без реального исходного
  APK соответствующей версии и проверки патча на устройстве.
- LSPatch от LSPosed архивирован с 2023 года; совместимость Android 17
  не гарантируется. Не распространяем чужие APK или ключи подписи.
- Не включён Google YouTube APK; репозиторий содержит только оригинальный
  код вкладки и заглушки API, необходимые для компиляции.
- После интеграции VPN потребуется VpnService и пользовательское
  подтверждение Android. Сторонние движки требуют проверки лицензий
  и совместимости с текущей версией YouTube.

## Сборка

Открыть Actions → Build YouFree YouTube in-app tab module → Artifacts.
Собранный `youfree-tab-debug.apk` — это **только модуль для инъекции**,
НЕ готовый YouTube.apk.

Из готового APK YouTube, право использования которого есть у пользователя,
и этого модуля LSPatch умеет делать patch в embedded-режиме.
См. документацию LSPatch: https://github.com/LSPosed/LSPatch
Нужен совместимый оригинальный APK (иногда split APK не поддерживается).
Нельзя гарантировать результат без проверки конкретной версии YouTube.

## Дальнейшая работа

1. Проверить модуль на точной целевой бета-версии YouTube и найти её native
   navigation view. При необходимости заменить эвристический hook стабильным
   fingerprint для этой версии.
2. Встроить проверенный сетевой движок (VPN + Byedpi) в пропатченный APK
   с нужными permissions и opt-in.
3. Проверить, что системная учётная запись, видеопотоки и Shorts работают.
4. Только затем публиковать устанавливаемую сборку.
